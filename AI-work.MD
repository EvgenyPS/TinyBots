# AI-work

## Проект

TinyBots — локальный пульт над ботами. Репозиторий публичный: имена, пути и id задаются конфигом, в git лежат только вымышленные демо-данные. Сервер слушает `127.0.0.1`. Лицензия Apache-2.0.

Пульт строится из `config.yaml` и записок. Бриф собирается для главного чата (если такого бота нет — для главного проекта) и копируется в буфер или открывается ссылкой `grokbot://`. Мастер настройки пишет свой `config.yaml`, если файла ещё нет.

## Что в этом дереве

- npm workspaces: `packages/schema`, `apps/server` (Hono), `apps/web` (Vite + React, тёмная оболочка).
- `npm start` собирает страницу и открывает браузер. Нет своего `config.yaml` — корень открывает мастер. Демо-набор остаётся по `?demo=1`. Другой набор: `TINYBOTS_CONFIG=demo/sets/beta/config.yaml`.
- API: `/api/launcher`, `/api/projects`, `/api/roster`, `/api/chats`, `/api/notes`, `/api/tasks`, `/api/sync`, `/api/brief`, `/api/setup`. `/api/bots` читает `demo/bots.json`.
- Битый конфиг не роняет процесс: `422` с файлом, строкой и причиной. Время в зоне из конфига. Записка старше `stale_after_hours` — «устарело». Нет файла или он битый — «нет записки». Шапка: «данные на ЧЧ:ММ» по самому позднему `updated_at` в `sync/*.json`.
- Запись файла — временный файл и `rename`. На Windows `EPERM`/`EBUSY` повторяются несколько раз с паузой. Единственный HTTP-запись — `POST /api/setup`: схема до диска, токен, порт через тот же `requestAllowed`.
- Host и Origin принимаются только с портом этого процесса. Чужой порт — 403.
- Бриф: один клик по задаче в колонке чата. Не больше 8 строк. Копирование кладёт в буфер текст превью. Ссылка `grokbot://app/v1/agent?id=<id>` только для id, который проходит формат. Рядом всегда «Если чат не открылся, откройте <имя> вручную». Пауза или нет главного — ошибка «Выберите главного», без превью.
- Очередь по умолчанию выключена (`delivery: clipboard`). Планировщик `queue` не пускает второй запуск в те же сутки зоны конфига. Файл очереди не пишется.
- Карточка бота — оверлей поверх орбиты. Размер и положение орбиты не меняются.
- Мастер: семь шагов. Существующий файл не меняется без подтверждения. `demo/` и `config.example.yaml` не перезаписываются. Папка без своего git показывает «вкладка Git будет скрыта».
- Пустые проекты, боты и записки: текст и кнопка «Настроить» → `/setup`.
- Ручной прогон мастера за 10 минут: `docs/setup-manual.md`.
- `npm test` — vitest. `npm run e2e` — Playwright 1.65. CI: Node 20/24, Ubuntu и Windows.

## Не в этом дереве

Мерж-модалка, SSE, блокировка одного писателя, запись `outbox/queue`, вкладки Git/Файлы/Документация, эффекты орбиты.
