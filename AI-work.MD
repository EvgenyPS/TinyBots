# AI-work

## Проект

TinyBots — локальный пульт над ботами. Репозиторий публичный: имена, пути и id задаются конфигом, в git лежат только вымышленные демо-данные. Сервер слушает `127.0.0.1`. Лицензия Apache-2.0.

Пульт строится из `config.yaml` и записок. Бриф собирается для главного чата (если такого бота нет — для главного проекта) и копируется в буфер или открывается ссылкой `grokbot://`. Мастер настройки и мерж ещё не сделаны.

## Что в этом дереве

- npm workspaces: `packages/schema`, `apps/server` (Hono), `apps/web` (Vite + React, тёмная оболочка).
- `npm start` собирает страницу и открывает пульт. Нет своего `config.yaml` — берётся `demo/sets/primary`. Другой набор: `TINYBOTS_CONFIG=demo/sets/beta/config.yaml`.
- API: `/api/launcher`, `/api/projects`, `/api/roster`, `/api/chats`, `/api/notes`, `/api/tasks`, `/api/sync`, `/api/brief`. `/api/bots` читает `demo/bots.json`.
- Битый конфиг не роняет процесс: `422` с файлом, строкой и причиной. Время в зоне из конфига. Записка старше `stale_after_hours` — «устарело». Нет файла или он битый — «нет записки». Шапка: «данные на ЧЧ:ММ» по самому позднему `updated_at` в `sync/*.json`.
- Запись файла — временный файл и `rename`. На Windows `EPERM`/`EBUSY` повторяются несколько раз с паузой. HTTP не пишет (405), CSRF будет вместе с первой записью.
- Host и Origin принимаются только с портом этого процесса. Чужой порт — 403.
- Бриф: один клик по задаче в колонке чата. Не больше 8 строк. Копирование кладёт в буфер текст превью. Ссылка `grokbot://app/v1/agent?id=<id>`. Пустой id — имя и «откройте чат вручную». Пауза или нет главного — ошибка «Выберите главного», без превью.
- Очередь по умолчанию выключена (`delivery: clipboard`). Планировщик `queue` не пускает второй запуск в те же сутки зоны конфига. Файл очереди не пишется.
- Карточка бота — оверлей, координаты орбиты не меняются.
- Пустые проекты, боты и записки: текст и кнопка «Настроить» → `/setup` (заглушка).
- `npm test` — vitest. `npm run e2e` — Playwright 1.65. CI: Node 20/24, Ubuntu и Windows.

## Не в этом дереве

Мастер настройки (B17–B19), мерж-модалка, SSE, блокировка одного писателя, запись `outbox/queue`, вкладки Git/Файлы/Документация, эффекты орбиты.
