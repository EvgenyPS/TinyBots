Demo Game — модуль демо

Аддон для экспорта и работы с пресетами прямо из редактора.

Состав.

  • plugin.gd — регистрация дока и команд
  • export/src/app.txt — пресеты и превью
  • ui/layout.txt — панель в редакторе

Задачу можно принимать, если превью видно в доке, тесты зелёные, и Рев видит доказательство в PR #3.
