# Ручная проверка вкладок v1

Чеклист после дословного быстрого старта из README. Данные — демо, настоящие имена и пути сюда не пишем. Автопроверка этих пунктов — e2e; здесь то, что человек смотрит глазами.

## Подготовка

- [ ] Node.js 20 или новее.
- [ ] Из корня репозитория выполнены ровно эти две команды и ничего между ними не менялось:

```
npm install
npm start
```

- [ ] Браузер открыл `http://127.0.0.1:8787`.
- [ ] Своего `config.yaml` нет — виден мастер. Ссылка «Открыть демо» открывает `?demo=1` и пульт Demo Game.

## Файлы

- [ ] Вкладка «Файлы» показывает дерево `demo-project`.
- [ ] `docs/README.md` и `docs/ACCEPTANCE.md` стоят правее и ниже папки `docs`, а не на одной линии с ней.
- [ ] На графе три подписи: «вызывает», «отдаёт кадр», «описывает».
- [ ] Клик по файлу подсвечивает строку дерева и узел графа.

## Документация

- [ ] «Документация» открывает `docs/README.md`: таблица и блок кода.
- [ ] `docs/xss.md` показывает текст `<script>` как текст. Браузер не выполняет его, картинки с `onerror` нет.

## Git

- [ ] В `.env` пустой `GITHUB_TOKEN`. Вкладка «Git» видна (у демо есть репозиторий) и пишет, что токена нет. Списка коммитов нет.
- [ ] Токен в исходниках страницы (`apps/web/dist`) не встречается.
- [ ] Набор `TINYBOTS_CONFIG=demo/sets/no-notes/config.yaml npm start` вкладку «Git» не показывает. «Файлы» показывают `notes/field.md`.

## Движение

- [ ] В системе включено «уменьшить движение». Орбита и смена вкладок не анимируются.
- [ ] При обычном движении переходы короткие и не двигают ширину или цвет.

## Что сюда не входит

Эффекты орбиты из раздела E и протокол ботов из раздела F.
