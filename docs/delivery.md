# Доставка брифа

Основной способ — буфер и ссылка. С экрана проекта кнопка задачи вызывает `GET /api/brief`. Превью — не больше 8 строк. «Скопировать бриф» пишет в буфер этот текст. «Открыть чат главного» ведёт на `grokbot://app/v1/agent?id=<id из конфига>`, если id проходит проверку формата. Рядом со ссылкой всегда текст «Если чат не открылся, откройте <имя бота> вручную»: протокол из браузера может не открыться. Пустой или битый id ссылки не даёт, подсказка с именем остаётся.

Кому уходит: главный чата, иначе главный проекта. Пауза или отсутствие главного — ошибка «Выберите главного», превью не показывается.

Очередь (`delivery: queue`) в конфигах по умолчанию выключена. Планировщик разрешает один запуск в календарные сутки зоны конфига, общий для расписания и кнопки. Запись `outbox/queue` этим срезом не делается.

Если главный — свой API-бот, клик по задаче сам вызывает `POST /api/brief/send`. Буфер и `grokbot://` для него не обязательны. Ответ модели показывается текстом. Записка пишется в `status/<bot_id>.json`, только если тело проходит схему. Мусор оставляет прежний файл. Задача, главный и исполнитель от записки не меняются. У бота Grok доставка прежняя: буфер и ссылка.
