# Ручная проверка мастера (B19)

Критерий: человек, который не видел проект, настраивает свой проект за 10 минут или быстрее.
Автоматически проверяются число шагов (7, потолок 10) и полный проход в браузере быстрее 2 минут (`e2e/b19-wizard-time.spec.ts`).
Этот лист — для живого прогона с таймером. Пока его не прошёл новый человек, пункт B19 не закрыт галочкой владельца.

## Условия

- Чистая копия репозитория, Node.js 20 или новее.
- Своего `config.yaml` нет. Если файл уже лежит в корне, переименуйте его, чтобы увидеть первый запуск.
- Секреты в мастер не вводятся. Токены остаются в `.env`, этот проход их не спрашивает.
- `data_dir` — относительный путь внутри лаунчера, не служебное имя. Папка проекта может быть любой, в том числе вне папки лаунчера.

## Таймер

Запустите таймер до `npm start`. Остановите, когда на пульте видно имя вашего проекта.
Pass: пульт открылся и `config.yaml` появился не позже 10:00.
Дальше 10:00 — fail, даже если шаги понятны.

## Чек-лист

Семь экранов. На каждом одна группа полей и кнопка «Дальше». На последнем — «Записать и открыть пульт».

- [ ] `npm install`, затем `npm start`. Браузер открыл мастер, не пульт. Видны шаги: Владелец, Боты, Проект, Чаты, Источник, Доступ, Доставка, Экономия.
- [ ] Владелец: имя, галочка подтверждения мержа стоит. «Дальше».
- [ ] Боты: имя и роль одного бота. Аватар можно не заполнять. «Дальше».
- [ ] Свой API-бот (если нужен): галочка, инструкции, провайдер и модель из списка. Пункт «своя» открывает ручной ввод. Имя ключа и `base_url` уже подставлены. Id, имя ключа и адрес — под «Дополнительно». Само значение ключа сюда не вводится: оно задаётся в окне «Ключи».
- [ ] Проект: название. Главный и исполнитель мержа — этот бот. «Дальше».
- [ ] Чаты: название чата. Участник отмечен. «Дальше».
- [ ] Источник: путь к папке с файлами проекта. Папка может лежать вне лаунчера. «Проверить путь». Если в папке нет своего git, видна фраза «вкладка Git будет скрыта». «Дальше» после этого всё равно доступна.
- [ ] Доставка: оставьте «Скопировать бриф». Очередь по умолчанию выключена. «Дальше».
- [ ] Экономия: короткий ответ, 3 пробуждения, 6 часов. «Записать и открыть пульт».
- [ ] Пульт показывает имя проекта и владельца. Файл `config.yaml` лежит в корне и не содержит токенов.
- [ ] Время на таймере не больше 10 минут.

## Если конфиг уже был

Мастер не затирает его молча. Пока не отмечена замена, файл на диске тот же.
Файлы в `demo/` и `config.example.yaml` мастер не перезаписывает.

## Ключ своего бота

В `config.yaml` остаётся только имя переменной, например `DEEPSEEK_API_KEY`. Значение в файл, в репозиторий и в пульт не кладётся.

Положить значение в хранилище ОС (Windows Credential Manager, macOS Keychain, Linux Secret Service). Сервис — `tinybots`, учётная запись — имя ключа. Команда читает значение со стандартного ввода и не показывает его. Аргументом значение не передавайте.

```
npm run secret:set -- DEEPSEEK_API_KEY
```

Если запись с этим именем уже есть, команда её не затирает. Для замены добавьте `--replace`:

```
npm run secret:set -- DEEPSEEK_API_KEY --replace
```

Проверка печатает только статус, без значения: «есть в хранилище», «есть в хранилище (в .env тоже — не используется)», «есть в .env» или «нет».

```
npm run secret:check -- DEEPSEEK_API_KEY
```

Сервер сначала читает хранилище и ждёт не дольше 2 с. Если модуль не загрузился, хранилища нет или оно зависло, берётся то же имя из `.env`, пульт в это время отвечает. Ответ запоминается до перезапуска. Команды удаления ключа нет.
