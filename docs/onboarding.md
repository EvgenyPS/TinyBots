# Онбординг

`npm start` собирает страницу и открывает пульт на `127.0.0.1`. Нет своего `config.yaml` — корень открывает мастер. Демо остаётся по `?demo=1`.

Мастер (0.3.3) — восемь шагов на shadcn/ui. На шаге «Боты» у каждого бота можно выбрать встроенный аватар и цвет. «Без аватара» ничего не дописывает. Своему API-боту над инструкциями предлагается шаблон, текст можно поправить. Id нового бота заканчивается на `-bot` (из имени, латиницей). Уже лежащий в конфиге id без суффикса мастер не переписывает. Свой путь к картинке, если он нужен, лежит в «Дополнительно». Ключ в мастер не вводится: только имя переменной, значение — в окне «Ключи».

Ручная проверка первого прохода (B19, 10 минут): `docs/setup-manual.md`.
Канон этого репозитория лежит рядом: план, архитектура, контракт, критерии, макет.
