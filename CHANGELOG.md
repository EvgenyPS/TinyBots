# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.
Каждый смерженный PR повышает версию и дописывает запись сюда. Тег `vX.Y.Z` ставится после мержа.

## [Unreleased]

## [0.3.3] — 2026-11-26

### Добавлено

- Мастер, шаг «Боты». Над инструкциями своего API-бота — список шаблонов: «Помощник», «Разработчик», «Ревьюер кода», «Тестировщик», «Автор текстов», «Аналитик», «Своя». Выбор подставляет короткий текст, его можно дописать. Если текст уже правили руками, другой шаблон спрашивает, прежде чем заменить. «Своя» после ручной правки поле не стирает.

### Изменено

- Новый id бота в мастере собирается из имени и суффикса `-bot`: «Ревик» → `revik-bot`, пустое имя → `bot1-bot`. Ручной ввод без суффикса дополняется при уходе из поля или при переходе дальше, второй раз суффикс не клеится. Совпадение автогенерации получает номер (`revik2-bot`), ручной дубль остаётся ошибкой у поля. Уже записанные конфиги не мигрируют: id без суффикса по-прежнему проходит схему. Id проекта и чата без суффикса.

## [0.3.2] — 2026-11-26

### Добавлено

- Мастер настройки на shadcn/ui и Tailwind v4. Preflight выключен, токены light/dark только у мастера, остальной пульт не перекрашивается. Рейл со степпером, карточка шага, узкий экран меньше 720px.
- Встроенные аватары v3: кнопка 72px открывает выбор из 12 персонажей и 10 цветов. В конфиг бота пишутся необязательные `avatarId` и `avatarColor`. «Без аватара» эти поля не пишет. Прежний `avatar` (путь к своей картинке) остаётся.

## [0.3.1] — 2026-11-26

### Изменено

- Мастер, шаг «Боты». У своего API-бота модель выбирается из списка провайдера, последним пунктом — «своя». Имя переменной ключа и `base_url` подставляются сами и лежат в свёрнутом блоке «Дополнительно» вместе с id. Ручная правка не затирается сменой модели. Смена провайдера обновляет только поля, которые человек не трогал. Имя и роль, провайдер и модель стоят по два в ряд.

## [0.3.0] — 2026-11-26

### Добавлено

- Закрытый канал ключей. Владелец задаёт в пульте имя, описание, заголовок, флаг «можно в теле», allowlist и ботов. Значение уходит только в хранилище ОС и обратно не читается.
- Инструмент `http_request`: одна подстановка `{{secret:NAME}}` в заданный заголовок или, если флаг включён, в тело. URL, редирект и частный адрес отвергаются. Соединение идёт на уже проверенный IP.
- Журнал вызовов без значения и предел частоты на ключ. Ответ боту маскирует значение и его кодировки.

### Исправлено

- `secret:set` без `--replace` отказывает до запроса значения, если запись уже есть.
- Дочерние процессы (хранилище, git, браузер, проверка папки) не получают ключи из `.env` и хранилища. Процесс чтения связки стартует с узким окружением.

## [0.2.0] — 2026-11-26

### Добавлено

- Ключ своего бота читается из хранилища ОС (сервис `tinybots`, учётная запись — имя ключа), затем из `.env`. В конфиге по-прежнему только имя. `npm run secret:set` пишет значение без эха, `npm run secret:check` печатает только статус. Команды удаления нет.

### Исправлено

- Чтение хранилища идёт в отдельном процессе и не дольше 2 с: зависшая связка не останавливает пульт, дальше берётся `.env`, повторно хранилище в этом процессе не спрашивается. Значение в журнал не пишется.
- `secret:check`, если ключ есть и в хранилище, и в `.env`, пишет «есть в хранилище (в .env тоже — не используется)».
- `secret:set` не заменяет уже лежащую запись без `--replace`.
- Скрытый ввод отбрасывает стрелки и Esc-последовательности.

## [0.1.0] — 2026-11-22

Первый собранный пульт: то, что уже есть в `main` после запросов на слияние 1–8.

### Добавлено

- Локальный пульт на `127.0.0.1`: конфиг, демо-наборы, записки, задачи и чаты.
- Бриф и доставка текста своему боту по API.
- Мастер настройки, который пишет `config.yaml`, если своего файла ещё нет.
- Запросы на мерж: решение и отзыв владельца уходят в `data_dir/outbox/`.
- Вкладки Git, файлы и документация проекта.
- Свои боты на OpenAI-совместимом ключе: пресеты DeepSeek и Qwen, свой `base_url`, значение ключа только в `.env`.
- Инструменты проекта `off`, `read` и `propose`. Правка лежит в `data_dir/proposals/`. В режиме files — снимок, в git — локальная ветка `tinybots/proposal-<id>` без пуша. Применяет и откатывает владелец.
- Потолок каталога предложений 256 МиБ и предупреждение пульта от 80%.

### Исправлено

- Откат, который не выполнился, не пишет «ничего не записано»: правка остаётся в проекте, повтор того же состояния не дописывает json.
- Обрыв записи предложения стирает временный каталог, если процесс ещё жив. После kill недописанную папку снимает следующий старт. Каталог `proposals`, который сам является ссылкой или junction, не разбирается. Папка со снимком `backup/` не снимается, даже если json рядом нет.
