Каждый смерженный PR повышает версию и дописывает запись сюда. Тег `vX.Y.Z` ставится после мержа.

## [Unreleased]

## [0.2.0] — 2026-11-26

### Добавлено

- Ключ своего бота читается из хранилища ОС (сервис `tinybots`, учётная запись — имя ключа), затем из `.env`. В конфиге по-прежнему только имя. `npm run secret:set` пишет значение без эха, `npm run secret:check` печатает только статус. Команды удаления нет.

## [0.1.0] — 2026-11-22

Первый собранный пульт: то, что уже есть в `main` после запросов на слияние 1–8.

### Добавлено

- Локальный пульт на `127.0.0.1`: конфиг, демо-наборы, записки, задачи и чаты.
- Бриф и доставка текста своему боту по API.
- Мастер настройки, который пишет `config.yaml`, если своего файла ещё нет.
- Запросы на мерж: решение и отзыв владельца уходят в `data_dir/outbox/`.
- Вкладки Git, файлы и документация проекта.
- Свои боты на OpenAI-совместимом ключе: пресеты DeepSeek и Qwen, свой `base_url`, значение ключа только в `.env`.
- Инструменты проекта `off`, `read` и `propose`. Правка лежит в `data_dir/proposals/`. В режиме files — снимок, в git — локальная ветка `tinybots/proposal-<id>` без пуша. Применяет и откатывает владелец.
- Потолок каталога предложений 256 МиБ и предупреждение пульта от 80%.

### Исправлено

- Откат, который не выполнился, не пишет «ничего не записано»: правка остаётся в проекте, повтор того же состояния не дописывает json.
- Обрыв записи предложения стирает временный каталог, если процесс ещё жив. После kill недописанную папку снимает следующий старт. Каталог `proposals`, который сам является ссылкой или junction, не разбирается. Папка со снимком `backup/` не снимается, даже если json рядом нет.
