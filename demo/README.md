# Демо

Вымышленные боты и проект. Ни одного реального имени, пути или id чата.
`bots.json` — список каркаса, его по-прежнему отдаёт `GET /api/bots`. Имена совпадают с `config.example.yaml`.
`demo/data/` — по три валидных примера на каждый файл контракта. Их разбирает vitest схемами из `packages/schema`.
`demo/sets/` — наборы пульта (primary, beta и три пустых). Пульт читает их как config.yaml. Описание — в `demo/sets/README.md`.
Битые примеры в этот каталог не кладутся: их собирает сам тест.
