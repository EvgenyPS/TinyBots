# Демо-наборы пульта

Вымышленные конфиги для экрана и e2e. Имена, пути и id не настоящие.

| Набор | Зачем |
|---|---|
| `primary` | Demo Game: Ава, Бит, Тэст, Рев. Зона Europe/Moscow. Записки свежая, устаревшая и отсутствующая. Свой git и дерево `demo-project/` (файлы, граф, markdown). |
| `beta` | Второй набор: Demo Harbor, другие имена. Зона America/New_York. |
| `no-projects` | В конфиге нет проектов. |
| `no-bots` | В конфиге нет ботов. |
| `no-notes` | Проект и бот есть, файлов статуса нет. Своего git нет, вкладка Git скрыта, дерево — `demo-project/`. |
| `lead-cases` | Пауза главного, пустой grok id, главный только у проекта, главного нет. Владелец Север. |
| `api-keys` | Свой бот Нора (DeepSeek, ключ только именем переменной) и бот Grok Бит. Задача на Норе, чат мержа «Сборка». |

`data_dir: data` считается от папки конфига. Битые конфиги сюда не кладутся: их собирает тест.
